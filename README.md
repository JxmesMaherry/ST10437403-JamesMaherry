## About Me

I'm a Computer Science & Information Systems graduate with a strong interest in the intersection of **software engineering, cloud infrastructure, and cybersecurity**.

My work focuses on designing reliable applications, developing secure backend services, and building systems that are straightforward to test, deploy, and maintain.

I enjoy working across the software development lifecycle, from system architecture and implementation to containerisation, automated testing, and security-focused delivery.

My primary areas of interest include:

- **Software Engineering** — Backend development, full-stack applications, clean architecture, REST APIs, and system design.
- **Cloud Security** — Secure cloud architecture, identity and access management, vulnerability intelligence, and defensive engineering.
- **DevSecOps** — CI/CD pipelines, automated security checks, dependency management, and container security.
- **Platform Engineering** — Docker, reproducible development environments, infrastructure automation, and reliable deployment workflows.
- **Data Engineering & Analytics** — Python pipelines, data processing, analytical modelling, and security intelligence.
